# Transformation Hint

Use `<<transform-hint "horse" "softbrown">>` outside a choice link to display a transformation label. The first argument is a framework translation key. The second is a CSS colour class supplied by your mod, such as `blue`, `orange`, `gold`, or `softbrown`; the framework does not impose a colour.

This macro only displays the label, like a vanilla animal-transformation hint. It does not change transformation progress. It displays nothing when numerical hints are hidden by `blindStatsEnabled`.
